# 🌍 Geoportal para Tesis de Maestría

## 🎯 Objetivo

A través de **Leaflet**, se creó un geoportal interactivo para mostrar las capas geográficas derivadas del proyecto de tesis de **Juan Manuel Chávez Rebollar**, alumno de la Maestría en Análisis Espacial y Geoinformática de la **Universidad Autónoma del Estado de México**.

El objetivo principal de este trabajo fue identificar patrones de distribución y concentración de la pérdida y recuperación del empleo formal del IMSS en los municipios del Estado de México durante el periodo 2020-2022. Además, se estimó una forma local de regresión para analizar los determinantes del empleo formal. El propósito final de este análisis fue identificar los municipios, sectores poblacionales y económicos prioritarios para la implementación de políticas públicas que favorezcan el empleo formal, así como reconocer las variables influyentes para el impulso de los puestos de trabajo formales.

---

## 🛠️ Tecnologías, Paquetes y Herramientas

Este proyecto se desarrolló utilizando las siguientes tecnologías y herramientas:

- **R**: Lenguaje de programación utilizado para el procesamiento de datos y la creación del geoportal.
- **Leaflet**: Biblioteca para crear mapas interactivos y visualizaciones geoespaciales.

---

## 📂 Estructura del Proyecto

El código está organizado de la siguiente manera:

1. **Importación de Resultados**: Carga de los resultados generados con software como **GeoDa** y **GWR** (Geographically Weighted Regression).
2. **Análisis Estadístico**: Realización de estadísticas descriptivas y preparación de los datos para su visualización en Leaflet.
3. **Definición de Paletas de Colores**: Personalización de colores para representar distintos valores en las capas geoespaciales.
4. **Creación del Geoportal**: Implementación del geoportal en **Leaflet**, incorporando funcionalidades como capas base, minimapa, leyendas y otros elementos interactivos.

---

## 📑 Notas

La publicación de este proyecto tiene fines demostrativos, con el objetivo de evidenciar capacidades técnicas en el desarrollo de sistemas interactivos de análisis económico y territorial utilizando **R**. 

Debido a las restricciones de tamaño de archivo en GitHub, la carpeta de datos no ha sido cargada. El proyecto se presenta únicamente con el código y los elementos esenciales para mostrar el funcionamiento del geoportal.
